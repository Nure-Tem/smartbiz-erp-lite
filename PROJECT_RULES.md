# SmartBiz ERP Lite - Project Rules

The backend already exists in Supabase.

Rules:

- NEVER create a new database.
- NEVER generate SQL migrations.
- NEVER rename tables.
- NEVER rename columns.
- NEVER remove existing functionality.
- NEVER replace Supabase authentication.
- NEVER create mock backend data.
- ONLY connect the frontend to the existing backend.

Technology:

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase

The goal is to connect the frontend to the existing Supabase project without changing the backend.
